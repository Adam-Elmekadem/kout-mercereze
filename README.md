# Mercereze

An independent luxury fashion concept and interactive portfolio storefront for Kout Project.

## Run locally

```powershell
npm install
npm run dev
```

Open `http://localhost:3000`. For a production check, run `npm run check` and `npm run build`.

## Included

- Responsive landing page with campaign hero, three-piece capsule, materials story, editorial lookbook, and concept index.
- Night / Atelier theme toggle saved in the browser.
- Accessible native product quick view with size selection.
- Local demo bag with item removal and total. No checkout or payment processing.
- Original split-M vector mark and five generated concept images.
- [Brand system](./BRAND_SYSTEM.md) and [image prompts](./IMAGE_PROMPTS.md).

## Production handoff

Replace concept renders and indicative prices with photographed products and real inventory. Connect a commerce backend, fulfillment and policies before offering transactions. Set the final site domain in the metadata configuration before deployment, then add a social preview image. Obtain trademark clearance for the brand name and mark in each intended market.
